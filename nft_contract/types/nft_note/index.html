    A partial instance of a NFTNote. This value represents a private commitment to the owner, randomness and storage slot, but the token id field has not yet been set. A partial note can be completed in public with the complete function (revealing the token id to the public), resulting in a NFTNote that can be used like any other one (except of course that its token id is known).
