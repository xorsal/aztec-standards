Contract VaultDeployer

@title VaultDeployer @notice Atomically deploys a Vault + shares token pair when this contract instance is created. @dev Each pool deploys a new VaultDeployer instance whose initializer runs deploy_vault or deploy_vault_with_initial_deposit. The vault and shares addresses depend on this instance's address as deployer, so their preimage commits to the full parameter set (including shares class ID) through the deployer's initialization hash, unlike a reusable factory.

 Computes both child addresses on-chain from class IDs, salts, and constructor args. Both
 children use this deployer instance (non-universal deploy) so that:
 1. publish_contract_instance_for_public_execution passes the deployer check
 2. vault.set_shares_token passes the deployer == msg_sender check

 The SDK must register the same instance preimages with the PXE before deploying this
 contract so the get_contract_instance oracle can resolve them.
